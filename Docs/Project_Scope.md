# Project Scope

# Project Title

Commercial Business Analysis of Airline Ticket Pricing

# Objective

Analyze airline ticket pricing data to identify revenue opportunities, customer booking behavior, pricing trends, and route performance for business decision-making.

# In Scope

- Data Cleaning
- Data Validation
- Exploratory Data Analysis
- KPI Generation
- Airline Performance Analysis
- Route Performance Analysis
- City Performance Analysis
- Booking Window Analysis
- Revenue Analysis
- Business Report Generation
- Business Insights Documentation
- Power BI Dashboard 
- SQL Analysis 


## Out of Scope
- Machine Learning
- Demand Forecasting
- Real-time Flight Tracking
- Passenger Sentiment Analysis
- Weather Forecast Integration
- Cost Optimization Models
- Airline Profit Calculation
- Fleet Scheduling

## Stakeholders
- Airline Management
- Commercial Team
- Pricing/Revenue Team
- Revenue Management Team
- Business Analysts 
- Executive Leadership - CEO / CMO  

# Expected Outcomes

- Identify high-performing airlines
- Identify profitable routes
- Understand booking behavior
- Discover pricing patterns
- Support pricing strategy
- Improve commercial decision-making
