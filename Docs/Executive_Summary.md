# Project Objective
The objective of this project is to analyze airline ticket pricing data and identify business opportunities that can improve revenue, pricing strategy, customer experience, and operational efficiency.

# Dataset
Source:
Kaggle - Airline Ticket Price Dataset

Records:
Approximately 300,000+ airline tickets records. 

# Business Questions
- Which airline generates the highest revenue?
- Which routes are the most profitable?
- How does booking window affect ticket prices?
- Which departure timings command premium pricing?
- Which cities contribute the highest revenue?
- Which ticket class generates maximum revenue?
- Which routes should airlines prioritize?

# Key KPIs
- Total Flights
- Total Revenue
- Average Ticket Price
- Average Flight Duration
- Revenue by Airline
- Revenue by City
- Revenue by Route
- Booking Window Analysis
- Airline Performance
- Route Performance

# Deliverables
- Cleaned Dataset

# Business Value
This project demonstrates how data can support airline pricing strategy, route optimization, and commercial decision-making through structured business analysis.
